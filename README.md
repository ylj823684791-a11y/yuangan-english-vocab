# 远感外贸英语

重庆远感科技水质在线监测 / 外贸销售专业词汇学习工具。静态站点，可本地预览，也可部署到 GitHub Pages 或任意静态托管。

## 功能

- **词库**：合并千问静态页、Codex 词库与产品/外贸词表，并按行业场景扩充（传感器、Modbus/RS485、校准运维、Incoterms、泳池/二供、余氯覆膜/无膜等）
- **闪卡**：翻卡学释义、例句；标记「已掌握 / 学习中 / 收藏」
- **测验**：四选一，错题自动记入错题本；选项去重，避免重复干扰项
- **词库浏览**：搜索、分类、岗位路径筛选
- **发音**：优先有道词典真人音（`dictvoice`，可切换美音/英音），失败再回退到浏览器 `speechSynthesis`（强制英文 voice）
- **进度**：本机 `localStorage` 保存掌握数、学习中、收藏、错题、连续天数、档案名；支持 **导出 / 导入 JSON**（换设备或换浏览器请用导出文件迁移）

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。

生产构建：

```bash
npm run build
npm run preview
```

构建产物在 `dist/`，可直接丢到任意静态服务器。

## 静态部署（GitHub Pages 示例）

1. 将本仓库推到 GitHub（建议私有仓库）
2. 仓库 Settings → Pages → 用 GitHub Actions 或把 `dist/` 发布到 `gh-pages` 分支
3. 本项目 `vite.config.ts` 已设置 `base: './'`，相对路径部署一般无需再改

也可把 `dist/` 上传到公司内网 Nginx / OSS / 任意静态托管。

## 进度说明

- 默认保存在当前浏览器的 localStorage（键名 `yg-english-progress-v1`）
- **清除站点数据、无痕模式、换浏览器或换电脑都会丢进度**
- 在「进度」页导出 JSON，到另一台设备导入即可恢复
- 「学习档案名」仅用于本机区分不同销售人员，不会上传服务器

## 发音说明

1. 优先请求有道公开 TTS：`https://dict.youdao.com/dictvoice?audio=TERM&type=2`（美音）或 `type=1`（英音）；词组会做 `encodeURIComponent`
2. 对含特殊符号、过长句子等不适合词典音的条目，或 Audio 播放失败时，回退到 `speechSynthesis`，并筛选 `lang` 以 `en` 开头的 voice（优先 en-US / en-GB）
3. 播放前会取消上一轮音频，避免叠音；按钮有加载 / 失败状态提示

> 有道接口为公开词典服务，若公司网络拦截外网音频，可改用浏览器合成语音（页面会自动回退）。

## 使用场景定位

词库面向**水质传感器 / 在线分析仪公司的中国销售**，服务海外出差、展会与项目沟通：产品参数、现场安装接线、Modbus/4-20 mA、外贸单证与 Incoterms，以及少量签证/酒店等出行用语。例句优先采用远感英文说明书与产品手册中的真实表达，并提供 2–3 条可轮换场景句。

## 例句说明

词条含 2–3 条场景例句（`examples`），闪卡/词库/测验按词条轮换展示，减少“Please confirm…”类模板感。安装、管件、电气与通讯词参考水质仪表说明书常见英文（接线、24 VDC、干接点、NPT 等）。

### 服务端

- 静态站 + API：`/opt/yuangan-vocab`
- API 进程：`systemctl status yuangan-vocab`（Python，监听 `127.0.0.1:3001`）
- Nginx：80 端口反代 `/api`，其余走前端 `dist`
- 数据库：`/opt/yuangan-vocab/server/data/vocab.db`

若外网打不开，请在阿里云控制台检查该 ECS 的**安全组**是否放行入方向 **TCP 80**（源 `0.0.0.0/0`）。
